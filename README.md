## 📋 Overview

**Insurance Cost Predictor** is an end-to-end machine learning application that estimates annual medical insurance costs based on individual health and demographic factors. The project combines advanced ML modeling with a modern React frontend and FastAPI backend, providing real-time predictions through an intuitive user interface.

## ✨ Key Features

- **🤖 ML Model Comparison** - Evaluates 7+ algorithms including XGBoost, LightGBM, Random Forest, and Stacking Ensemble
- **🔧 Advanced Feature Engineering** - Creates 70+ advanced features including interactions, polynomial terms, and risk factors
- **🎯 Real-time Predictions** - Instant cost estimation through React frontend with FastAPI backend
- **📱 Responsive UI** - Modern, gradient-themed interface that works on desktop and mobile devices
- **🔍 Input Validation** - Comprehensive client-side validation with real-time error feedback
- **📦 Model Persistence** - Saves best model and transformer using joblib for production deployment
- **🐳 Docker Support** - Containerized application for easy deployment
- **🚀 CI/CD Pipeline** - Automated builds and deployments with GitHub Actions

## 🛠️ Technology Stack
